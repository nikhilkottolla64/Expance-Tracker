#  Expense Tracker Web App

A simple and user-friendly Expense Tracker application built using HTML, CSS, and JavaScript. This app helps users manage their income and expenses efficiently with real-time updates and category-based tracking.

---

## Features

-  Add income and expense transactions
-  Delete transactions
-  Data stored using localStorage (persists after refresh)
-  Category-based transaction system (Food, Travel, Shopping)
-  Filter transactions by category
-  Real-time balance, income, and expense calculation

##  How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in your browser  
   OR  
4. Use Live Server in VS Code  

---

##  How It Works

- Users can add transactions with amount and category  
- Positive values are treated as income  
- Negative values are treated as expenses  
- Data is stored in browser localStorage  
- UI updates dynamically without page reload
